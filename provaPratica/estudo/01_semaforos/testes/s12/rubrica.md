# Requisitos de implementação — s12

O teste de todos os contadores e a alteração inteira ocorrem na mesma região crítica. Não consumir parcialmente. API deve ser segura para chamadas concorrentes; os casos ordenados tornam o resultado verificável.

O script compila e executa todos os casos. Confira estes requisitos no código: resultados corretos não provam que você usou a primitiva exigida. Não há entrega de resposta teórica/JSON; a entrega é o programa C.
