# Testes p04

O corretor compara os tokens em ordem, ignorando diferenças de espaços e quebras de linha.

As entradas ficam em `01.in`, `02.in`, ...; as saídas em `.out`; `casos.json` é o manifesto. Edite o C em `../../respostas/p04.c` e execute `python3 corrigir.py` nesta pasta. Não edite casos para acomodar uma saída errada.
