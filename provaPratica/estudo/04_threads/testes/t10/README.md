# Testes t10

O corretor compara o multiconjunto de linhas, aceitando qualquer ordem, mas preservando a quantidade de repetições.

As entradas ficam em `01.in`, `02.in`, ...; as saídas em `.out`; `casos.json` é o manifesto. Edite o C em `../../respostas/t10.c` e execute `python3 corrigir.py` nesta pasta. Não edite casos para acomodar uma saída errada.
