# Requisitos de implementação — x01

Teste de limite e incremento na mesma região crítica. Cada trabalhador usa cópia local do índice. Não usar divisão estática: o objetivo é implementar corretamente a reserva global.

O script compila e executa todos os casos. Confira estes requisitos no código: resultados corretos não provam que você usou a primitiva exigida. Não há entrega de resposta teórica/JSON; a entrega é o programa C.
